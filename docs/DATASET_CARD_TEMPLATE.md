Replace YAML with the dataset's actual script/language, license and tasks. The example task above is a placeholder, not a classification decision.

## Dataset description

ID, version, original publisher, upstream citation and persistent source URL.

## Data structure

Formats, fields, splits, record counts and count evidence. Document nullable fields.

## Creation and annotation

Collection method, consent, annotation protocol, annotator qualifications and agreement. Disclose machine translations, synthetic content and AI assistance. Identify the precise human review scope.

## Licensing and attribution

## Uses, risks and limitations

## Reproduction and checks
