# Dataset licensing and ethics policy

Project code and original documentation are MIT. That license does not apply to the dataset text.

## Klam

Klam combines only sources with explicit CC0, CC BY, CC BY-SA, or sufficiently evidenced public-domain rights. Each record retains its source, version, applicable license, evidence URL, and attribution. Klam does not apply a single new license to all records. CC BY requires attribution. CC BY-SA adaptations must retain share-alike obligations. Public-domain and CC0 records retain their status.

Sources are pinned to immutable revisions or checksummed archives. If a component's redistribution rights are unclear, it stays out until the evidence is resolved. Public availability alone is not permission. Noncommercial, no-derivatives, research-only, unspecified, and terms-restricted sources are not included.

Automated language identification, deduplication, and privacy-pattern screening do not constitute human verification. Rows remain `unreviewed` until a reviewer, date, and review scope are recorded.

## Attribution and reuse

When using or redistributing Klam, preserve these per-record fields with each text: `license`, `license_url`, `attribution`, `source_id`, `source_version`, `source_record_id`, and `source_locator`. The release `LICENSE` and `SOURCES.md` explain the source terms; the row license is authoritative for that record.

## Privacy and corrections

Pattern scans are triage, not proof that a dataset contains no personal information. Report a rights or privacy concern through the repository's issue tracker without posting the affected text. The maintainer should investigate provenance and take appropriate steps. Removal from a current version cannot erase previous downloads, caches, or forks.
