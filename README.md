# open-urdu-datasets

A community Urdu and Roman Urdu dataset hub with provenance, license tracking, and verification tooling.

**Status: setup in progress.** No datasets have been cataloged, hosted, or verified in this repository yet. No release has been published.

## Scope

Discover datasets through original sources; document licenses, provenance, limitations, and verification evidence. Host records only when redistribution is explicitly permitted. Restricted or unverifiable datasets remain link-only.

## Licensing

The MIT license applies to project code and original project documentation only. It does not grant rights to third-party datasets, source text, or annotations. Each dataset retains its own license and attribution requirements; no dataset is relicensed by this project.

## Review and contributions

Changes will use feature branches and pull requests after initialization. Urdu text drafted with AI assistance remains `review_status: unreviewed` until confirmed by a human reviewer. Model answers are not evidence that a dataset is correct.

## Roadmap

- Research original sources and build an evidence-backed catalog, targeting at least 25 verified entries without padding.
- Document redistribution, attribution, content warnings, and removal procedures.
- Add schemas, conservative text processing, validation tools, tests, and loading examples.
- Include real vocabulary and paired records only after provenance, redistribution rights, and review requirements are satisfied.
- Publish v0.1.0 only after checks pass and maintainer approval.
