# کلام (Klam)

**جائزے کی حالت: غیر جائزہ شدہ۔** یہ تعارفی متن انسانی جائزے کا منتظر ہے۔

کلام اردو اور رومن اردو کے متن کو ایک آسان ڈیٹا سیٹ اور ایک مستقل ریکارڈ فارمیٹ میں جمع کرتا ہے۔ استعمال کے لیے Hugging Face سے صرف کلام لوڈ کریں؛ ہر ریکارڈ میں متن، کام کی قسم، ماخذ، لائسنس، حوالہ اور جائزے کی حالت موجود ہے۔

کلام میں مختلف ماخذ کے لائسنس شامل ہیں۔ ہر ریکارڈ کے ساتھ اس کا لائسنس اور حوالہ محفوظ ہے، اس لیے پوری کلیکشن کے لیے ایک ہی لائسنس کا دعویٰ نہیں کیا جاتا۔ ابھی کسی ریکارڈ کا مقامی اردو بولنے والوں نے جائزہ نہیں لیا؛ ریکارڈز کو انسانی طور پر تصدیق شدہ نہیں کہا جاتا۔
