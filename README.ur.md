# کلام (Klam)

**حالت: تیاری جاری ہے۔** کلام کا اصل ڈیٹا سیٹ ابھی اشاعت کے لیے تیار نہیں۔

کلام میں صرف ایسا اردو متن شامل ہوگا جو کلام کے لیے لکھا گیا ہو، جسے مصنف نے واضح اجازت دی ہو، یا جس کے عین متن اور ایڈیشن کے عوامی ملکیت میں ہونے کی تصدیق ہو۔ ہر ریکارڈ میں ماخذ، حقوق، حوالہ اور جائزے کی حالت درج ہوگی۔

پہلے کے دوسرے ڈیٹا سیٹس کلام میں شامل نہیں ہوں گے۔ موجودہ ماخذ رجسٹری خالی ہے، اس لیے ابھی کلام کا ڈیٹا لوڈ نہیں کیا جا سکتا۔ انسانی جائزہ مکمل ہونے تک متن کو غیر جائزہ شدہ ہی رکھا جائے گا۔
